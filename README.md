# Medical Appointment System - Assignment 1
This is a Java console program for Assignment 1, following Module 1 to Module 3 requirements.

## Features
- Interactive menu
- Two pre-added appointments
- 8-digit patient phone number validation
- Prevent duplicate appointment for the same practitioner at the same time
- Sort appointments by time
- Cancel appointment with patient name, phone, practitioner ID and time slot

## Class list
- MedicalPractitioner (abstract superclass)
- GP, Specialist, Nurse, Dietitian (subclasses)
- Patient
- Appointment
- AppointmentManager
- AssignmentOne (Main class)

## Run instruction
Open all Java files in VS Code and run AssignmentOne.java
